手占い｜解析した手の写真表示・指先5回タップ 修正版
================================================

設置方法
1. このフォルダ内の index.html と image フォルダをセットでHTTPSサーバーへアップロードしてください。
2. 既存のindex.htmlは新しいものに上書きします。ブラウザに旧画面が残る場合は強制再読み込みしてください。
3. 既存の画像を維持したまま差し替える場合は、サーバー側の image フォルダに次の画像を保存してください。

画像
・image/soyaku_logo.png   研究所ロゴ（同梱）
・image/hand_result.png  診断結果の60秒後に表示（同梱）
・image/result_extra.png 診断結果の直下に即時表示（任意・未同梱）
・image/finger_puzzle.png 中指5回タップ時のポップアップ画像（任意・未同梱）
※ファイル名の大文字・小文字は区別されます。

修正した点
・写真の描画方法をcanvasからimgに変更しました。
・結果画面に切り替える前に写真の読み込みを確定するため、撮影画面を閉じたあとも写真が消えません。
・解析結果表示時に画面が下へスクロールされたまま残らないようにしました。
・写真の表示サイズに合わせて指先の判定位置を計算します。
・中指の指先を5回タップすると画像ポップアップが開き、×で閉じられます。
・中指のタップ判定を広げました（写真表示サイズに応じて半径34〜68px）。
・タップ5回目の直後にポップアップが開いた場合でも、誤って即時に閉じないようにしました。
・未配置のfinger_puzzle.pngはポップアップに「追加資料を表示できませんでした。」と表示します。

表示順
1. 解析した手の写真
2. あなたの健康状態
3. result_extra.png（設置した場合のみ、診断結果と同時）
4. hand_result.png（60秒経過後、表示時に result_extra.png は消える）

時間経過と再訪
・診断結果の表示から60秒でhand_result.pngが表示され、表示後は消えません。
・result_extra.pngは60秒までは表示され、hand_result.pngが出た瞬間に非表示になります。
・LINEなどへ移動しても、同じタブに戻れば実時間に基づき残り時間を判定します。
・新たに撮影すると、新しい診断結果から60秒を数え直します。
・写真と診断結果は端末内に一時保持します。ページを再読み込みすると再撮影が必要です。
・写真はサーバーには送信しません。手の解析モデルはオンラインで読み込みます。

検証
・PC（Chromium）とスマートフォンサイズのエミュレーションで、画像の表示、
  中指4回では反応しないこと、5回目で開くこと、×で閉じることを確認しています。
・60秒後の表示判定と、再撮影時の状態クリアを確認しています。
・手のAI認識モデルは模擬データで検証したため、実機で撮影した手での最終確認が必要です。

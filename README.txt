手占い / 第０創薬化学研究所
HTML単体で動く静的Webアプリ

【設置方法】
1. index.html をHTTPS対応のご自身のサーバーにアップロードしてください。
2. スマートフォンまたはPCのブラウザで index.html のURLを開いてください。
3. カメラへのアクセスを許可して撮影するか、画像ファイルを選択してください。
4. 写真に片手が認識された場合のみ、占い結果の画面へ移動します。
5. 結果をコピーし、LINEの助手アカウントに貼り付けて送信します。

【同梱内容】
index.html : Webアプリ本体（HTML・CSS・JS一体型）
README.txt : 本書

【重要な技術仕様】
・サーバー側プログラムやAPIキーは不要です。
・初回の画像認識時、Google MediaPipe のJavaScript/WASMと手の認識モデルを
  外部CDNからダウンロードします。初回はネットワーク接続が必要です。
・撮影画像そのものを外部サーバーへアップロードする処理は含まれていません。
・画像はブラウザ内で解析します。解析後はアプリの処理用メモリから破棄します。
・占い文はアプリ内で用意した文章をランダムに組み合わせて自動生成します。
  テキスト生成APIを呼び出すものではありません。
・「体内に悪性の成分が検出されました。」は全結果の末尾に必ず追加されます。
・これはフィクションのゲーム演出です。健康状態・疾病の医学的判定は一切行いません。

【判定精度について】
・MediaPipe Hand Landmarkerを使用し、手の特徴点が認識された場合に通過します。
・指の本数や肌色を判定条件として指定していません。
・指の欠損を含む手が検出されることはありますが、あらゆる形状・肌色について
  検出できることを保証するものではありません。
・足やその他の部位を意図的に通過させる処理はありませんが、
  認識AIの性質上、誤判定の可能性はゼロにはできません。
・実際の本番運用前に、複数のスマートフォン、照明条件、手の状態などで
  撮影試験を実施してください。精度要件が厳密な場合は学習済モデルの調整が必要です。

【動作環境】
HTTPS上の最新のChrome、Safari等を想定しています。
ローカルでHTMLを直接開いた場合やHTTP公開の場合、ブラウザがカメラを制限する
ことがあります。画像ファイルから選ぶ方式は代替として利用できます。

【編集箇所】
・タイトル／説明文　：HTML上の見出し・段落
・結果の固定文言　　：script内 ALERT_LINE 定数
・占い候補文　　　　：script内 readings オブジェクト
・認識エンジン設定　：script内 MP_VERSION / MP_MODEL など

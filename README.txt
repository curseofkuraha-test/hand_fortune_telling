第０創薬化学研究所「手占い」指先タップ版

[アップロード]
index.html と image/ フォルダをそのまま HTTPS サーバーに配置してください。

[同梱画像]
image/soyaku_logo.png    研究所のロゴ
image/hand_result.png    ゲーム外の案内画像

[追加が必要な画像]
image/finger_puzzle.png  5回タップで開く新しい謎の画像（未同梱）
画像は比率自由。ファイル名を完全に一致させてください。
謎画像が未配置なら、ポップアップ内で「追加資料を表示できませんでした。」と表示されます。

[遊び方・仕様]
1. 手の甲か手のひらを正面から撮影します。
2. 手を認識でき、正面に近いと判定できれば結果画面へ移ります。
3. 解析が完了すると、診断結果より上に、撮影した手の写真をそのまま表示します。表示された写真の中指の指先を連続で5回タップすると、追加の謎が表示されます。
4. ×ボタン、背景タップ、Escキーで閉じられます。

[仕様の切り替え]
index.html の const FINGERTIP_MODE = 'middle';
を 'any' に変えると、同じ指先なら中指以外でも5回タップで成立します。
const REQUIRED_FINGER_TAPS = 5; で必要タップ回数を変更できます。

[注意点]
・手の検出はMediaPipeを利用。端末内で処理し、写真をアップロードしません。
・判定モデルの取得にはインターネット接続が必要です。
・手のひら／甲の正面判定は形状を使った近似です。側面・傾きを完全には見分けられません。
・一部の指が写っていない写真では、指先の位置を正確に検出できないことがあります。
・このページの健康状態の表示はゲーム上の演出であり、実際の健康診断ではありません。

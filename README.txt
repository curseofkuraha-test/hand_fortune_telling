ひらめき弁当 | 手占い (ロゴ対応・脳活性化所見追加版)

【サーバー設置】
1. このZIPに入っている index.html と image フォルダを、構成を保ったまま自サーバーの同じ公開ディレクトリに置いてください。
2. 手元の第０創薬化学研究所ロゴを PNG 形式で image/soyaku_logo.png として配置してください。
3. HTTPS でアクセスしてください。スマートフォンのカメラ利用には HTTPS が必要です。
4. 撮影・再撮影・手の認識・結果表示・コピー操作を実機でご確認ください。

【ロゴ】
・ロゴがまだ置かれていない場合は、ヘッダーに研究所名を文字で表示します。
・ロゴに含まれる研究所名は二重表示しません。
・image/README.txt に詳細があります。

【結果文章】
・ゲーム上の健康所見3箇所を各4種からランダムに選択します（計64パターン）。
・すべての結果に「脳の活動が活性化」「ひらめき力が高まっている」の文章が入ります。
・最後の固定文「体内に悪性の成分が検出されました。」を含めて133〜145文字です。
・画像から本人の健康状態を推測して内容を変える機能ではなく、手の認識成功後にランダム生成します。
・最後の警告文と助手へのコピーボタンは従来どおりです。コピー対象は警告文のみです。

【認識とプライバシー】
・2画面構成: 撮影／解析結果
・Google MediaPipe HandLandmarker を利用し、手として認識できた画像だけを受け付けます。
・画像解析は端末内で行い、写真のサーバー送信・保存処理はありません。
・認識に必要なプログラムと学習済みモデルは初回に外部CDNから読み込みます。
・手指の欠損や特殊な形状での認識精度、足などの誤認識を完全に排除できることは保証できません。
・本アプリの健康所見はゲーム上の演出であり、医療上の健康診断ではありません。

【変更する場合】
・見た目: index.html 内 <style> の :root 変数（--blue, --orange など）
・検査文: index.html 内 <script> の readings / BRAIN_FINDING
・助手への案内: index.html 内 <aside class="handoff">

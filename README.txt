手占い：サーバー設置用パッケージ

【内容】
index.html : 手占い本体（HTML単体、CSSとJavaScriptを内蔵）
image/hand_result.png : いただいたゲーム外のご案内画像（正方形）
image/soyaku_logo.png : 研究所のロゴ配置先（現時点で画像未同梱）

【公開方法】
1. ZIPを展開し、index.htmlとimageフォルダを同じ階層でHTTPS対応サーバーにアップロードしてください。
2. ロゴのPNG画像をsoyaku_logo.pngという名前でimageフォルダに追加してください。
3. スマートフォンでアクセスして、カメラの利用を許可してください。
4. 外カメラを優先起動し、撮影ボタンはカメラの直下に表示されます。

【認識モデル】
Google MediaPipe のJavaScript・WASM・モデルは初回アクセス時に外部CDN等からダウンロードします。利用にはインターネット接続が必要です。
画像の解析は端末内で行い、写真をサーバーへアップロードするコードはありません。
手が認識された場合に限り結果画面へ進みますが、手指の欠損があるケースや手足の取り違えを完全に防止できる保証はありません。

【演出・注意事項】
健康状態の文章はゲーム内の創作であり医療診断ではありません。主な所見はランダム（64通り）に変化し、脳活動の所見と最後の警告文は固定です。
ゲーム外の進行案内はimage/hand_result.pngをそのまま表示します。HTMLの送信指示・コピーボタンは廃止しました。
